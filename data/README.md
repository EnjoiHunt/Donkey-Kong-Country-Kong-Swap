Derived tables only, with no game graphics:

- `dkc1_frame_names.json`: DKC1 sprite-frame index → ROM offset → name (names from Yoshifanatic1's DKC1 disassembly, GPL-3.0)
- `dkc2_kong_gfx.json`: DKC2 graphic IDs used by Diddy's and Dixie's animation scripts
- `dkc3_all.json`: offsets of DKC3 sprite frames
- `spin_gids.json`: DKC2 graphic IDs of Dixie's helicopter-spin frames
- `kiddy_frames.inc`: Kiddy frame names and offsets in DKC3, from DKC1Recomp (MIT, © 2026 DKC1Recomp contributors)
- `inactive_M.npy`: a 4×3 colour transform fitted to DKC1's own "partner" palettes
